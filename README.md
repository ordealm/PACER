# PACER
## Code Release Status

This repository accompanies our published paper, **"Self-Corrected Speech Reasoning: Diagnosing and Improving Condition Updating via PACER"**.

The code and scripts are currently being cleaned, organized, and documented to improve reproducibility and ease of use. The repository is therefore not yet complete, and the remaining scripts and detailed usage instructions will be added progressively.

Thank you for your interest and patience. Please stay tuned for updates.
